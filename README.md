# Junqiao Fan Homepage

Static academic homepage ready for GitHub Pages.

## Files
- `index.html`: main page
- `assets/style.css`: stylesheet
- `assets/profile.jpg`: profile image
- `assets/wechat.jpg`: WeChat QR code
- `assets/Junqiao_Fan_CV.pdf`: CV PDF
- `.nojekyll`: disables Jekyll processing on GitHub Pages

## Deploy to GitHub Pages
1. Create a repository named `<username>.github.io` or any repository you want to publish.
2. Upload all files in this folder to the repository root.
3. In GitHub, go to **Settings -> Pages**.
4. Choose **Deploy from a branch**, select `main` and `/root`.
5. Wait for GitHub Pages to publish the site.

## Edit links
Search for `#` or `TODO` in `index.html` and replace placeholder project/PDF/code links when available.
